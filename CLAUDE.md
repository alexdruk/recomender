# Project rules

- Node 22 plain JavaScript for download and parsing. No TypeScript, no frameworks.
- Python (in a local .venv folder) for scoring and modelling only.
- Never put # comments inside terminal commands you show me.
- Explain things to me in plain, simple English.
- Do the work yourself. Do not ask me to write code or files.
- Commit after each working step with a -m message. In git merge commands always use -m.
- data/ and .venv/ are git-ignored. Never commit books or texts.
- Be polite to the Flibusta servers: one request at a time, a pause of
  at least 3 seconds between requests, and cache everything you download.
